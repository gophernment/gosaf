# GoSaf v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make GoSaf provably correct and measurably no slower and no more allocating than `sony/gobreaker` on its hot paths, give operators incident controls, and add release supply-chain tooling.

**Architecture:** Same layering as v0.1 (`gosaf -> internal/guard -> internal/circuit`). The domain gains operator modes and a lock-free "reject window"; the guard gains a value-type `Ticket` path (`Begin`/`End`), a shared immutable rejection error, a monotonic default clock, an atomic reject window and richer snapshots; the facade gains `ForceOpen`/`Disable` and re-exports. A new stdlib-only package `gosafslog`, a separate `bench/` module (the only place gobreaker appears) and release workflows complete the release.

**Tech Stack:** Go 1.27.2, standard library only in the root module (adds `log/slog`, `testing/synctest`). `bench/` requires `github.com/sony/gobreaker/v2 v2.4.0`.

**Spec:** `docs/superpowers/specs/2026-10-14-gosaf-v0.2-design.md` (builds on `2026-10-14-gosaf-core-design.md`)

## Global Constraints

- Root `go.mod` keeps `go 1.27.2` and **zero `require` lines**. gobreaker may only appear in `bench/go.mod`.
- No lock held while running user code (`fn`, `IsFailure`, `Listener`, `RejectListener`).
- Domain package (`internal/circuit`) never reads the clock or locks; time is passed in.
- Shared error values are immutable: `RejectedError` has **unexported** fields.
- New behavior is test-first; every exported identifier has a doc comment; `gofmt -l .` prints nothing.
- The release gate (`cd bench && go run ./gate`) must pass before tagging: GoSaf median ns/op no more than 2% above gobreaker and allocs/op not higher on "Closed, success" and "Open, reject".
- GitHub Actions pinned by commit SHA; workflows use least-privilege `permissions`.
- Tags are signed (`git tag -s`), never moved after push. **Signing, tagging and pushing are done by the repository owner, not by the executor** (see Task 5).

## Review Focus

Failure modes the spec implies that most need a pinned test, most likely first:

1. **Stale lock-free reject window**: the published window must never outlive the Open state. After Open to Half-Open, after `Reset`/mode change, and after a clock step back inside the old window, a call must go through the locked path. Tests: Task 1 `TestFastRejectStopsWhenOpenTimeoutPasses`, `TestFastRejectStopsAfterReset`, `TestFastRejectFollowsClockStepBack`, `TestStaleFastWindowDoesNotOutliveTheOpenState`.
2. **Concurrent control and calls**: `ForceOpen`/`Disable`/`Reset` racing with `Do` must not race, panic or leave the breaker unusable after `Reset`. Test: Task 1 `TestConcurrentModeChangesAndCalls` (run with `-race`).
3. **Allocation regressions**: the hot paths must stay allocation-free. Tests: Task 1 `TestDoClosedPathDoesNotAllocate`, `TestDoRejectPathDoesNotAllocate`; Task 4 gate (allocs/op).
4. **Forced/disabled modes**: forced open has no retry time (`RetryAfter() == 0`, `RetryAt().IsZero()`), never half-opens; disabled records nothing and keeps the state; both end only with `Reset`. Tests: Task 1 `TestForceOpenRejectsWithoutRetryTimeAndNeverRecovers`, `TestDisabledAdmitsEverythingAndRecordsNothing`, `TestResetEndsForcedModes`, `TestForcedOpenRejectsWithoutRetryTimeUntilReset`.
5. **Logging leaks and optional interface**: `gosafslog` must never log error text; a `Listener` without `OnReject` must cost nothing and not panic. Tests: Task 2 `TestListenerLogsStateChangesCallsAndRejections` (asserts a secret in an error is not logged), Task 1 `TestRejectListenerIsCalledOnlyWhenImplemented`.

```go
import (
	"testing"
	"time"

const (
	openTimeout  = 10 * time.Second
	probeTimeout = 3 * time.Second
)

func newMachine(halfOpenMax int) *circuit.Machine {
	return circuit.NewMachine(circuit.MachineConfig{
		Policy:           circuit.Policy{MinCalls: 4, FailureRate: 0.5, SlowRate: 0.5},
		OpenTimeout:      openTimeout,
		HalfOpenMaxCalls: halfOpenMax,

	}, circuit.NewCountWindow(10))

// call admits one call at now and records outcome o for it.
func call(t *testing.T, m *circuit.Machine, now time.Time, o circuit.Outcome) []circuit.Transition {
	t.Helper()
	adm, _ := m.Admit(now)
	if adm.Reject != circuit.Admitted {
		t.Fatalf("call rejected: %+v", adm)
	}
	return m.Record(now, adm.Gen, o)
}

func state(m *circuit.Machine, now time.Time) circuit.State {
	s, _ := m.Snapshot(now)
	return s
}

// tripOpen drives m from Closed to Open at time now.
func tripOpen(t *testing.T, m *circuit.Machine, now time.Time) {
	t.Helper()
	for range 4 {
		call(t, m, now, circuit.Failure)
	}
	if got := state(m, now); got != circuit.Open {
		t.Fatalf("state = %v, want open", got)
	}
}
```

```go
package circuit

import "time"

// MachineConfig holds the already-validated rules a Machine follows.
type MachineConfig struct {
	Policy           Policy
	OpenTimeout      time.Duration
	HalfOpenMaxCalls int
	ProbeTimeout     time.Duration
}

// Mode is an operator override of the normal state machine.
type Mode int

// Modes. Anything other than ModeNormal is explicit and lasts until Reset.
const (
	ModeNormal     Mode = iota
	ModeForcedOpen      // every call is rejected; no automatic Half-Open
	ModeDisabled        // every call is admitted and nothing is recorded
)

func (m Mode) String() string {
	switch m {
	case ModeNormal:
		return "normal"
	case ModeForcedOpen:
		return "forced-open"
	case ModeDisabled:
		return "disabled"
	default:
		return "unknown"
	}
}

// Transition describes a state change.
type Transition struct {
	From, To State
}

// Reject says why a call was not admitted.
type Reject int

// Admission results.
const (
	Admitted Reject = iota
	RejectedOpen
	RejectedHalfOpenFull
)

// Admission is the result of Machine.Admit.
type Admission struct {
	Gen    uint64 // pass back to Record; identifies the admitting generation
	Reject Reject
	// RetryAt is when a rejected caller may try again. It is the zero time when
	// no retry is scheduled (ModeForcedOpen). Valid when Reject != Admitted.
	RetryAt time.Time
}

type probes struct {
	admitted  int
	completed int
	pending   int
	counts    Counts
	deadline  time.Time
}

// Machine is the circuit state machine. It is not safe for concurrent use;
// the caller serialises access and supplies the current time.
type Machine struct {
	cfg      MachineConfig
	win      Window
	state    State
	mode     Mode
	gen      uint64
	openedAt time.Time
	half     probes
	consec   int // failures in a row while Closed; only tracked when enabled
}

// NewMachine returns a Closed machine.
func NewMachine(cfg MachineConfig, win Window) *Machine {
	return &Machine{cfg: cfg, win: win}
}

// Admit decides whether a call may run now.
func (m *Machine) Admit(now time.Time) (Admission, []Transition) {
	switch m.mode {
	case ModeDisabled:
		return Admission{Gen: m.gen}, nil
	case ModeForcedOpen:
		return Admission{Reject: RejectedOpen}, nil
	}

	var ts []Transition
	if m.state == Open && now.Before(m.openedAt) {
		m.openedAt = now // clock stepped back: restart the wait instead of sticking
	}
	if m.state == Open && !now.Before(m.openedAt.Add(m.cfg.OpenTimeout)) {
		ts = append(ts, m.enter(HalfOpen, now))
	}
	if m.state == HalfOpen && m.half.pending > 0 &&
		(!now.Before(m.half.deadline) || m.half.deadline.Sub(now) > m.cfg.ProbeTimeout) {
		// A probe never reported back (or the clock stepped back past its
		// deadline): fail closed and re-open.
		ts = append(ts, m.enter(Open, now))
	}

	switch m.state {
	case Closed:
		return Admission{Gen: m.gen}, ts
	case Open:
		return Admission{Reject: RejectedOpen, RetryAt: m.openedAt.Add(m.cfg.OpenTimeout)}, ts
	}

	if m.half.admitted >= m.cfg.HalfOpenMaxCalls {
		return Admission{Reject: RejectedHalfOpenFull, RetryAt: m.half.deadline}, ts
	}
	if m.half.pending == 0 {
		m.half.deadline = now.Add(m.cfg.ProbeTimeout)
	}
	m.half.admitted++
	m.half.pending++
	return Admission{Gen: m.gen}, ts
}

// Record reports the outcome of a call admitted under generation gen.
// Results from an older generation are dropped.
func (m *Machine) Record(now time.Time, gen uint64, o Outcome) []Transition {
	if gen != m.gen || m.mode == ModeDisabled {
		return nil
	}
	switch m.state {
	case Closed:
		if o == Ignored {
			return nil
		}
		m.win.Record(now, o)
		if m.cfg.Policy.ConsecutiveFailures > 0 {
			if o == Failure {
				m.consec++
			} else {
				m.consec = 0
			}
		}
		if m.cfg.Policy.Tripped(m.win.Counts(now)) || m.cfg.Policy.ConsecutiveTripped(m.consec) {
			return []Transition{m.enter(Open, now)}
		}
	case HalfOpen:
		m.half.pending = max(m.half.pending-1, 0)
		if o == Ignored {
			m.half.admitted = max(m.half.admitted-1, 0) // free the probe slot
			return nil
		}
		m.half.completed++
		m.half.counts.add(o)
		// Re-open as soon as the probes seen so far make recovery impossible,
		// without waiting for the rest to finish against a failing dependency.
		if m.cfg.Policy.Doomed(m.half.counts, m.cfg.HalfOpenMaxCalls) {
			return []Transition{m.enter(Open, now)}
		}
		if m.half.completed < m.cfg.HalfOpenMaxCalls {
			return nil
		}
		return []Transition{m.enter(Closed, now)}
	}
	return nil
}

// Reset returns the machine to ModeNormal and Closed with an empty window,
// and drops all in-flight results.
func (m *Machine) Reset(now time.Time) []Transition {
	m.mode = ModeNormal
	from := m.state
	t := m.enter(Closed, now)
	if from == Closed {
		return nil
	}
	return []Transition{t}
}

// SetMode applies an operator override. ModeNormal is the same as Reset.
// ModeForcedOpen moves the machine to Open and keeps it there. ModeDisabled
// keeps the state but stops admitting-with-recording. In every case in-flight
// results are dropped.
func (m *Machine) SetMode(now time.Time, mode Mode) []Transition {
	switch mode {
	case ModeForcedOpen:
		m.mode = mode
		from := m.state
		t := m.enter(Open, now)
		if from == Open {
			return nil
		}
		return []Transition{t}
	case ModeDisabled:
		m.mode = mode
		m.gen++
		m.half = probes{}
		m.consec = 0
		return nil
	default:
		return m.Reset(now)
	}
}

// RejectWindow describes a period in which every call is rejected the same way
// without changing any state, so callers may reject without locking. While the
// machine is forced open, forever is true and the times are zero. While it is
// Open in normal mode, calls with from <= now < until are rejected with
// RetryAt = until. ok is false in every other situation.
func (m *Machine) RejectWindow() (from, until time.Time, forever, ok bool) {
	switch {
	case m.mode == ModeForcedOpen:
		return time.Time{}, time.Time{}, true, true
	case m.mode == ModeNormal && m.state == Open:
		return m.openedAt, m.openedAt.Add(m.cfg.OpenTimeout), false, true
	}
	return time.Time{}, time.Time{}, false, false
}

// Mode returns the current operator override.
func (m *Machine) Mode() Mode { return m.mode }

// Snapshot returns the stored state and the counts that drive it.
// An Open machine moves to HalfOpen lazily, on the next Admit.
func (m *Machine) Snapshot(now time.Time) (State, Counts) {
	if m.state == HalfOpen {
		return m.state, m.half.counts
	}
	return m.state, m.win.Counts(now)
}

func (m *Machine) enter(to State, now time.Time) Transition {
	t := Transition{From: m.state, To: to}
	m.state = to
	m.gen++
	m.half = probes{}
	m.consec = 0
	switch to {
	case Open:
		m.openedAt = now
	case Closed:
		m.win.Reset()
	}
	return t
}
```

```go
package guard

import (
	"errors"
	"fmt"
	"time"

	"github.com/gophernment/gosaf/internal/circuit"
)

// Sentinel errors for rejected calls. Match with errors.Is.
var (
	ErrOpen         = errors.New("gosaf: circuit open")
	ErrHalfOpenFull = errors.New("gosaf: half-open probe limit reached")
)

// RejectedError is returned when the circuit refuses a call. It carries no
// caller data. The same value is returned to every caller while the retry time
// is unchanged, so its fields are unexported and it is immutable.
type RejectedError struct {
	state   circuit.State
	retryAt time.Time
}

// State is Open or HalfOpen: the state that caused the rejection.
func (e *RejectedError) State() circuit.State { return e.state }

// RetryAt is when a caller may try again. It is the zero time when no retry is
// scheduled, which is the case while the breaker is forced open.
func (e *RejectedError) RetryAt() time.Time { return e.retryAt }

// RetryAfter is the time left until RetryAt, never negative. It is measured with
// the wall clock, not Config.Clock, and is 0 when no retry is scheduled.
func (e *RejectedError) RetryAfter() time.Duration {
	if e.retryAt.IsZero() {
		return 0
	}
	return max(time.Until(e.retryAt), 0)
}

func (e *RejectedError) Error() string {
	base := ErrOpen
	if e.state == circuit.HalfOpen {
		base = ErrHalfOpenFull
	}
	if e.retryAt.IsZero() {
		return fmt.Sprintf("%s (no retry scheduled)", base)
	}
	return fmt.Sprintf("%s (retry after %s)", base, e.RetryAfter().Round(time.Millisecond))
}

// Is makes errors.Is(err, ErrOpen) and errors.Is(err, ErrHalfOpenFull) work.
func (e *RejectedError) Is(target error) bool {
	switch target {
	case ErrOpen:
		return e.state == circuit.Open
	case ErrHalfOpenFull:
		return e.state == circuit.HalfOpen
	}
	return false
}
```

```go
import (

var errNilContext = errors.New("gosaf: nil context")

// StateChange is delivered to Listener.OnStateChange.

	At       time.Time
}

// CallEvent is delivered to Listener.OnCall. It carries no error text or payload.
type CallEvent struct {
	Name     string
	Outcome  circuit.Outcome
	Duration time.Duration
}

// RejectEvent is delivered to RejectListener.OnReject.
type RejectEvent struct {
	Name  string
	State circuit.State // Open or HalfOpen
}

// Listener observes the breaker. Methods run on the goroutine that caused the
// event, after the lock is released: a slow Listener slows that caller, but it
// may safely call back into the breaker. A panic in a method is recovered and
// dropped. Ordering across goroutines is not guaranteed.
type Listener interface {
	OnStateChange(StateChange)
	OnCall(CallEvent)
}

// RejectListener is an optional extension of Listener. If the configured
// Listener also implements it, OnReject is called for every rejected call. The
// reject path costs nothing extra when it is not implemented.
type RejectListener interface {
	OnReject(RejectEvent)
}

// Snapshot is a point-in-time copy of breaker state.
type Snapshot struct {
	Name       string
	State      circuit.State
	Mode       circuit.Mode
	Counts     circuit.Counts
	Rejected   uint64    // calls rejected since the breaker was created
	LastChange time.Time // wall time of the last state change; zero if none
}

// Options are the non-machine settings of a Guard.
type Options struct {
	Name             string
	SlowCallDuration time.Duration
	// IsFailure classifies errors; nil selects DefaultIsFailure.
	IsFailure func(error) bool
	// Clock supplies the time used for all decisions; nil selects MonotonicClock.
	Clock func() time.Time
	// Wall supplies timestamps shown to users (StateChange.At, Snapshot.LastChange);
	// nil selects Clock if it was set, otherwise time.Now.
	Wall     func() time.Time
	Listener Listener
}

// DefaultIsFailure counts every error except context.Canceled, which means
// the caller gave up rather than the dependency failing. A deadline that
// expires while waiting on the dependency is a failure.
func DefaultIsFailure(err error) bool {
	return err != nil && !errors.Is(err, context.Canceled)
}

// MonotonicClock returns a clock that reads only the monotonic clock. It is
// cheaper than time.Now, which also reads the wall clock. The returned times
// are only meant for measuring durations and ordering.
func MonotonicClock() func() time.Time {
	origin := time.Now()
	return func() time.Time { return origin.Add(time.Since(origin)) }
}

// Guard serialises access to a Machine.
type Guard struct {
	mu         sync.Mutex
	m          *circuit.Machine
	opts       Options
	now        func() time.Time
	wall       func() time.Time
	rejectL    RejectListener
	lastRej    *RejectedError
	lastChange time.Time

	// rejected counts rejected calls. fast, when set, describes a period in which
	// every call is rejected identically, so Begin can reject without taking mu.
	rejected atomic.Uint64
	fast     atomic.Pointer[fastReject]
}

// fastReject is an immutable copy of circuit.Machine.RejectWindow plus the
// shared error to return.
type fastReject struct {
	from, until time.Time
	forever     bool
	err         *RejectedError
}

// New returns a Guard around m.
func New(m *circuit.Machine, opts Options) *Guard {
	g := &Guard{m: m, opts: opts, now: opts.Clock, wall: opts.Wall}
	if g.now == nil {
		g.now = MonotonicClock()
		if g.wall == nil {
			g.wall = time.Now
		}
	}
	if g.wall == nil {
		g.wall = g.now
	}
	if g.opts.IsFailure == nil {
		g.opts.IsFailure = DefaultIsFailure
	}
	g.rejectL, _ = opts.Listener.(RejectListener)
	return g
}

// Ticket identifies one admitted call. It is a plain value: the allocation-free
// counterpart of Permit, for callers that report the result exactly once.
type Ticket struct {
	gen   uint64
	start time.Time
}

// Begin asks to make a call. It returns ctx.Err() if ctx is already done,
// without using a probe slot, or a *RejectedError if the circuit refuses.
func (g *Guard) Begin(ctx context.Context) (Ticket, error) {
	if ctx == nil {
		return Ticket{}, errNilContext
	}
	if err := ctx.Err(); err != nil {
		return Ticket{}, err
	}

	now := g.now()
	if fr := g.fast.Load(); fr != nil && (fr.forever || (!now.Before(fr.from) && now.Before(fr.until))) {
		g.rejected.Add(1)
		g.notifyReject(circuit.Open)
		return Ticket{}, fr.err
	}

	g.mu.Lock()
	adm, ts := g.m.Admit(now)
	var rej *RejectedError
	if adm.Reject != circuit.Admitted {
		rej = g.rejection(adm)
		g.rejected.Add(1)
	}
	if len(ts) > 0 {
		g.lastChange = g.wall()
	}
	if len(ts) > 0 || rej != nil {
		g.syncFast()
	}
	g.mu.Unlock()

	g.notifyStates(ts)
	if rej != nil {
		g.notifyReject(rej.state)
		return Ticket{}, rej
	}
	return Ticket{gen: adm.Gen, start: now}, nil
}

// End reports the result of a call admitted by Begin. Call it exactly once per
// Ticket; use Permit when that cannot be guaranteed.
func (g *Guard) End(tk Ticket, err error) {
	now := g.now()
	elapsed := max(now.Sub(tk.start), 0)
	outcome := g.classify(err, elapsed)

	g.mu.Lock()
	ts := g.m.Record(now, tk.gen, outcome)
	if len(ts) > 0 {
		g.lastChange = g.wall()
		g.syncFast()
	}
	g.mu.Unlock()

	g.notifyStates(ts)
	g.notifyCall(CallEvent{Name: g.opts.Name, Outcome: outcome, Duration: elapsed})
}

// Permit is the right to make one call. Call Done exactly once with the
// call's error; further calls are ignored.
type Permit struct {
	g    *Guard
	tk   Ticket
	done atomic.Bool
}

// Allow is Begin that returns a Permit with an idempotent Done.
func (g *Guard) Allow(ctx context.Context) (*Permit, error) {
	tk, err := g.Begin(ctx)
	if err != nil {
		return nil, err
	}
	return &Permit{g: g, tk: tk}, nil
}

// Done reports the call's result. It is idempotent and a no-op on a nil or
// zero-value Permit.
func (p *Permit) Done(err error) {
	if p == nil || p.g == nil || !p.done.CompareAndSwap(false, true) {
		return
	}
	p.g.End(p.tk, err)
}

// Snapshot returns a copy of the current state.
func (g *Guard) Snapshot() Snapshot {
	now := g.now()
	g.mu.Lock()
	defer g.mu.Unlock()
	s, c := g.m.Snapshot(now)
	return Snapshot{
		Name:       g.opts.Name,
		State:      s,
		Mode:       g.m.Mode(),
		Counts:     c,
		Rejected:   g.rejected.Load(),
		LastChange: g.lastChange,
	}
}

// SetMode applies an operator override; circuit.ModeNormal also closes the
// circuit and clears its window (Reset).
func (g *Guard) SetMode(mode circuit.Mode) {
	now := g.now()
	g.mu.Lock()
	ts := g.m.SetMode(now, mode)
	if len(ts) > 0 {
		g.lastChange = g.wall()
	}
	g.syncFast()
	g.mu.Unlock()
	g.notifyStates(ts)
}

// Reset returns to normal operation: closed, empty window, no forced mode.
func (g *Guard) Reset() { g.SetMode(circuit.ModeNormal) }

// syncFast publishes (or clears) the lock-free reject window so that it always
// matches the machine. Callers hold g.mu.
func (g *Guard) syncFast() {
	from, until, forever, ok := g.m.RejectWindow()
	if !ok {
		g.fast.Store(nil)
		return
	}
	if cur := g.fast.Load(); cur != nil && cur.forever == forever && cur.from.Equal(from) && cur.until.Equal(until) {
		return
	}
	retryAt := until
	if forever {
		retryAt = time.Time{}
	}
	g.fast.Store(&fastReject{from: from, until: until, forever: forever, err: g.sharedRejection(circuit.Open, retryAt)})
}

// rejection returns a shared, immutable error while the state and retry time
// are unchanged. Callers hold g.mu.
func (g *Guard) rejection(adm circuit.Admission) *RejectedError {
	st := circuit.Open
	if adm.Reject == circuit.RejectedHalfOpenFull {
		st = circuit.HalfOpen
	}
	return g.sharedRejection(st, adm.RetryAt)
}

// sharedRejection returns the cached error if it matches, else makes a new one.
// Callers hold g.mu.
func (g *Guard) sharedRejection(st circuit.State, retryAt time.Time) *RejectedError {
	if r := g.lastRej; r != nil && r.state == st && r.retryAt.Equal(retryAt) {
		return r
	}
	r := &RejectedError{state: st, retryAt: retryAt}
	g.lastRej = r
	return r
}

// classify runs user code (IsFailure) outside the lock.
func (g *Guard) classify(err error, elapsed time.Duration) circuit.Outcome {
	if err == nil {
		if elapsed > g.opts.SlowCallDuration {
			return circuit.Slow
		}
		return circuit.Success
	}
	if g.isFailure(err) {
		return circuit.Failure
	}
	return circuit.Ignored
}

// isFailure treats a panicking IsFailure as a failure (fail closed).
func (g *Guard) isFailure(err error) (failed bool) {
	defer func() {
		if recover() != nil {
			failed = true
		}
	}()
	return g.opts.IsFailure(err)
}

func (g *Guard) notifyStates(ts []circuit.Transition) {
	if len(ts) == 0 || g.opts.Listener == nil {
		return
	}
	at := g.wall()
	for _, t := range ts {
		ev := StateChange{Name: g.opts.Name, From: t.From, To: t.To, At: at}
		safely(func() { g.opts.Listener.OnStateChange(ev) })
	}
}

func (g *Guard) notifyCall(ev CallEvent) {
	if g.opts.Listener == nil {
		return
	}
	safely(func() { g.opts.Listener.OnCall(ev) })
}

func (g *Guard) notifyReject(st circuit.State) {
	if g.rejectL == nil {
		return
	}
	ev := RejectEvent{Name: g.opts.Name, State: st}
	safely(func() { g.rejectL.OnReject(ev) })
}

func safely(f func()) {
	defer func() { _ = recover() }()
	f()
}
```

```go
// Breaker is a circuit breaker. Create it with New; it is safe for concurrent use.
type Breaker struct {
	g *guard.Guard
}

// New validates cfg and returns a Breaker in the Closed state.
func New(cfg Config) (*Breaker, error) {
	if err := cfg.validate(); err != nil {
		return nil, err
	}
	clock, wall := cfg.Clock, cfg.Clock
	if clock == nil {
		clock, wall = guard.MonotonicClock(), time.Now
	}

	var win circuit.Window
	if cfg.WindowPeriod > 0 {
		win = circuit.NewTimeWindow(cfg.WindowSize, cfg.WindowPeriod, clock())
	} else {
		win = circuit.NewCountWindow(cfg.WindowSize)
	}
	m := circuit.NewMachine(circuit.MachineConfig{
		Policy: circuit.Policy{
			MinCalls:    cfg.MinCalls,
			FailureRate: cfg.FailureRate,
			SlowRate:    cfg.SlowCallRate,

			ConsecutiveFailures: cfg.ConsecutiveFailures,
		},
		OpenTimeout:      cfg.OpenTimeout,
		HalfOpenMaxCalls: cfg.HalfOpenMaxCalls,
		ProbeTimeout:     cfg.ProbeTimeout,
	}, win)

	return &Breaker{g: guard.New(m, guard.Options{
		Name:             cfg.Name,
		SlowCallDuration: cfg.SlowCallDuration,
		IsFailure:        cfg.IsFailure,
		Clock:            clock,
		Wall:             wall,
		Listener:         cfg.Listener,
	})}, nil
}

// Allow asks to make one call. On success the caller must call Permit.Done
// with the call's error (nil on success). Prefer Do, which does this for you.
// Errors: ctx.Err() if ctx is done, or a *RejectedError (ErrOpen, ErrHalfOpenFull).
func (b *Breaker) Allow(ctx context.Context) (*Permit, error) {
	if b == nil || b.g == nil {
		return nil, errNotInitialized
	}
	return b.g.Allow(ctx)
}

// Snapshot returns a copy of the current state and counts. A zero Breaker
// returns a zero Snapshot.
//
// The state is the stored one and changes lazily, on the next Allow: an Open
// circuit becomes HalfOpen only when a call arrives after OpenTimeout, and a
// probe that never finished re-opens the circuit only when a call arrives after
// ProbeTimeout. Until then Snapshot and State keep reporting the old state.
func (b *Breaker) Snapshot() Snapshot {
	if b == nil || b.g == nil {
		return Snapshot{}
	}
	return b.g.Snapshot()
}

// State returns the stored state; see Snapshot for when it changes.
func (b *Breaker) State() State { return b.Snapshot().State }

// ForceOpen opens the circuit and keeps it open: every call is rejected with
// ErrOpen until Reset. The circuit never moves to Half-Open by itself. Use it
// to shed load from a dependency during an incident.
func (b *Breaker) ForceOpen() {
	if b == nil || b.g == nil {
		return
	}
	b.g.SetMode(ModeForcedOpen)
}

// Disable turns the breaker into a pass-through: every call is allowed and
// nothing is recorded, until Reset. It removes protection, so use it only when
// the breaker itself is the problem.
func (b *Breaker) Disable() {
	if b == nil || b.g == nil {
		return
	}
	b.g.SetMode(ModeDisabled)
}

// Reset returns to normal operation: the circuit is closed, its statistics are
// cleared, any forced mode ends, and the results of calls still in flight are
// discarded. Use it from operational tooling, not the hot path.
func (b *Breaker) Reset() {
	if b == nil || b.g == nil {
		return
	}
	b.g.Reset()
}

// Do runs fn through the breaker. It returns a *RejectedError without calling
// fn when the circuit refuses, and ctx.Err() when ctx is already done.
// A panic in fn is recorded as a failure and then re-raised with the original
// value, so recover returns exactly what fn panicked with.
func Do[T any](ctx context.Context, b *Breaker, fn func(context.Context) (T, error)) (res T, err error) {
	if b == nil || b.g == nil {
		return res, errNotInitialized
	}
	tk, err := b.g.Begin(ctx)
	if err != nil {
		return res, err
	}

	finished := false
	defer func() {
		if finished {
			return
		}
		// fn panicked or called runtime.Goexit: free the slot, then let it continue.
		r := recover()
		b.g.End(tk, errPanicked)
		if r != nil {
			panic(r)
		}
	}()

	res, err = fn(ctx)
	finished = true
	b.g.End(tk, err)
	return res, err
}
```

```go
// Package gosafslog connects a gosaf.Breaker to log/slog.
package gosafslog

import (
	"context"
	"log/slog"

	"github.com/gophernment/gosaf"
)

// NewListener returns a gosaf.Listener that logs through l (slog.Default if l is
// nil). State changes are logged at Warn when the circuit opens and at Info
// otherwise; calls and rejections are logged at Debug. It never logs error text
// or payloads.
func NewListener(l *slog.Logger) gosaf.Listener {
	if l == nil {
		l = slog.Default()
	}
	return &listener{log: l}
}

type listener struct {
	log *slog.Logger
}

func (l *listener) OnStateChange(ev gosaf.StateChange) {
	level := slog.LevelInfo
	if ev.To == gosaf.Open {
		level = slog.LevelWarn
	}
	l.emit(level, "circuit state changed",
		slog.String("name", ev.Name),
		slog.String("from", ev.From.String()),
		slog.String("to", ev.To.String()),
		slog.Time("at", ev.At))
}

func (l *listener) OnCall(ev gosaf.CallEvent) {
	l.emit(slog.LevelDebug, "circuit call",
		slog.String("name", ev.Name),
		slog.String("outcome", ev.Outcome.String()),
		slog.Duration("duration", ev.Duration))
}

func (l *listener) OnReject(ev gosaf.RejectEvent) {
	l.emit(slog.LevelDebug, "circuit call rejected",
		slog.String("name", ev.Name),
		slog.String("state", ev.State.String()))
}

func (l *listener) emit(level slog.Level, msg string, attrs ...slog.Attr) {
	ctx := context.Background()
	if l.log.Enabled(ctx, level) {
		l.log.LogAttrs(ctx, level, msg, attrs...)
	}
}
```

```go
// These tests compare the real code with deliberately naive oracles (plain
// slices, linear scans, exact arithmetic) and check invariants over random
// operation sequences. They are written from the spec, not from the code.

func newRand(seed int) *rand.Rand { return rand.New(rand.NewPCG(uint64(seed), 0x9e3779b9)) }

func pickOutcome(r *rand.Rand) circuit.Outcome {
	return []circuit.Outcome{circuit.Success, circuit.Success, circuit.Failure, circuit.Slow}[r.IntN(4)]
}

// --- naive windows ---------------------------------------------------------

type naiveCount struct {
	n    int
	outs []circuit.Outcome
}

func (w *naiveCount) Record(_ time.Time, o circuit.Outcome) {
	w.outs = append(w.outs, o)
	if len(w.outs) > w.n {
		w.outs = w.outs[len(w.outs)-w.n:]
	}
}

func (w *naiveCount) Counts(time.Time) circuit.Counts { return tally(w.outs) }
func (w *naiveCount) Reset()                          { w.outs = nil }

type naiveRec struct {
	idx int64
	o   circuit.Outcome
}

type naiveTime struct {
	n      int
	width  time.Duration
	origin time.Time
	latest int64
	recs   []naiveRec
}

func (w *naiveTime) index(now time.Time) int64 {
	idx := int64(now.Sub(w.origin) / w.width)
	if idx < w.latest {
		idx = w.latest
	}
	w.latest = idx
	return idx
}

func (w *naiveTime) Record(now time.Time, o circuit.Outcome) {
	w.recs = append(w.recs, naiveRec{w.index(now), o})
}

func (w *naiveTime) Counts(now time.Time) circuit.Counts {
	cur := w.index(now)
	var outs []circuit.Outcome
	for _, r := range w.recs {
		if r.idx > cur-int64(w.n) && r.idx <= cur {
			outs = append(outs, r.o)
		}
	}
	return tally(outs)
}

func (w *naiveTime) Reset() { w.recs = nil }

func tally(outs []circuit.Outcome) circuit.Counts {
	var c circuit.Counts
	for _, o := range outs {
		c.Total++
		switch o {
		case circuit.Failure:
			c.Failures++
		case circuit.Slow:
			c.Slow++
		}
	}
	return c
}

func TestClosedTripMatchesNaivePolicy(t *testing.T) {
	type rate struct {
		v        float64
		num, den int
	}
	rates := []rate{{0.1, 1, 10}, {0.25, 1, 4}, {0.5, 1, 2}, {0.75, 3, 4}, {1, 1, 1}}

		size := 1 + r.IntN(12)
		minCalls := 1 + r.IntN(size)
		fr, sr := rates[r.IntN(len(rates))], rates[r.IntN(len(rates))]
		consecutive := r.IntN(5) // 0 disables
		m := circuit.NewMachine(circuit.MachineConfig{
			Policy: circuit.Policy{
				MinCalls: minCalls, FailureRate: fr.v, SlowRate: sr.v, ConsecutiveFailures: consecutive,
			},
			OpenTimeout: openTimeout, HalfOpenMaxCalls: 1, ProbeTimeout: probeTimeout,
		}, circuit.NewCountWindow(size))

		var hist []circuit.Outcome
		consec := 0
		for step := range 200 {
			o := []circuit.Outcome{circuit.Success, circuit.Failure, circuit.Failure, circuit.Slow, circuit.Ignored}[r.IntN(5)]

			want := false
			if o != circuit.Ignored {
				hist = append(hist, o)
				if o == circuit.Failure {
					consec++
				} else {
					consec = 0
				}

				if len(win) > size {

			if got != want {
				t.Fatalf("seed %d step %d (size %d min %d fr %v sr %v consec %d): tripped = %v, naive = %v; history %v",
					seed, step, size, minCalls, fr.v, sr.v, consecutive, got, want, hist)
			}
			if got {
				break
			}
		}
	}

func TestHalfOpenDecisionMatchesNaiveRule(t *testing.T) {
	for seed := range 400 {
		r := newRand(seed)
		probes := 1 + r.IntN(6)
		fr := []float64{0.25, 0.5, 0.75, 1}[r.IntN(4)]
		sr := []float64{0.25, 0.5, 0.75, 1}[r.IntN(4)]
		m := circuit.NewMachine(circuit.MachineConfig{
			Policy:      circuit.Policy{MinCalls: 1, FailureRate: fr, SlowRate: sr},
			OpenTimeout: openTimeout, HalfOpenMaxCalls: probes, ProbeTimeout: probeTimeout,
		}, circuit.NewCountWindow(4))
		// MinCalls is 1, so one failure trips the circuit
		if ts := call(t, m, t0, circuit.Failure); len(ts) != 1 {
			t.Fatalf("seed %d: setup failure did not trip (fr %v)", seed, fr)
		}

		now := t0.Add(openTimeout)
		tickets := make([]circuit.Admission, probes)
		for i := range tickets {
			tickets[i], _ = m.Admit(now)
			if tickets[i].Reject != circuit.Admitted {
				t.Fatalf("seed %d: probe %d not admitted: %+v", seed, i, tickets[i])
			}
		}

		fails, slows := 0, 0
		decided := false
		for k, idx := range r.Perm(probes) {
			o := pickOutcome(r)
			ts := m.Record(now, tickets[idx].Gen, o)
			if decided {
				if ts != nil {
					t.Fatalf("seed %d: result after the decision caused %+v", seed, ts)
				}
				continue
			}
			switch o {
			case circuit.Failure:
				fails++
			case circuit.Slow:
				slows++
			}
			// best case: every probe still to finish succeeds
			doomed := float64(fails)/float64(probes) >= fr || float64(slows)/float64(probes) >= sr
			var want circuit.State = -1
			switch {
			case doomed:
				want = circuit.Open
			case k+1 == probes:
				want = circuit.Closed
			}
			switch {
			case want == -1 && ts != nil:
				t.Fatalf("seed %d result %d: transition %+v, naive rule says keep waiting", seed, k, ts)
			case want != -1 && (len(ts) != 1 || ts[0].To != want):
				t.Fatalf("seed %d result %d: transitions %+v, naive rule says %v", seed, k, ts, want)
			}
			decided = want != -1
		}
	}
}

		OpenTimeout:      openTimeout,
		HalfOpenMaxCalls: probes,

				outstanding = append(outstanding, adm)
			case circuit.RejectedOpen:
				if m.Mode() == circuit.ModeNormal && (adm.RetryAt.Before(now) || adm.RetryAt.After(now.Add(openTimeout))) {
					t.Fatalf("op %d: open RetryAt %v outside [%v, %v]", i, adm.RetryAt, now, now.Add(openTimeout))
				}
			case circuit.RejectedHalfOpenFull:
				if adm.RetryAt.Before(now) || adm.RetryAt.After(now.Add(probeTimeout)) {
					t.Fatalf("op %d: half-open RetryAt %v outside [%v, %v]", i, adm.RetryAt, now, now.Add(probeTimeout))
				}
			}
			if m.Mode() == circuit.ModeDisabled && (adm.Reject != circuit.Admitted || ts != nil) {
				t.Fatalf("op %d: disabled machine must admit everything without transitions", i)
			}
		case opRecordOldest, opRecordNewest:
			if len(outstanding) == 0 {
				continue
			}
			k := 0
			if int(b)%8 == opRecordNewest {
				k = len(outstanding) - 1
			}
			o := []circuit.Outcome{circuit.Success, circuit.Failure, circuit.Slow, circuit.Ignored}[arg%4]
			ts = m.Record(now, outstanding[k].Gen, o)
			outstanding = append(outstanding[:k], outstanding[k+1:]...)
		case opAdvance:
			now = now.Add(steps[arg%len(steps)])
		case opBack:
			now = now.Add(-steps[arg%len(steps)] - time.Second)
		case opReset:
			if arg%8 != 0 { // rare, so sequences usually reach Half-Open
				continue
			}
			ts = m.Reset(now)
		case opMode:
			if arg%12 != 0 { // rare: forced modes would otherwise hide everything else
				continue
			}
			ts = m.SetMode(now, []circuit.Mode{circuit.ModeForcedOpen, circuit.ModeDisabled}[(arg/12)%2])
		case opSnapshot:
		}

		// transitions form a chain from the previous state to the current one
		cur, counts := m.Snapshot(now)
		from := prev
		for _, tr := range ts {
			if tr.From != from || tr.From == tr.To {
				t.Fatalf("op %d: bad transition chain %+v (previous state %v)", i, ts, prev)
			}
			from = tr.To
		}
		if from != cur {
			t.Fatalf("op %d: transitions %+v end in %v but state is %v", i, ts, from, cur)
		}
		if !timeWin && counts.Total > size {
			t.Fatalf("op %d: window holds %d calls, bound is %d", i, counts.Total, size)
		}
		if counts.Failures > counts.Total || counts.Slow > counts.Total || counts.Total < 0 {
			t.Fatalf("op %d: inconsistent counts %+v", i, counts)
		}
	}

	// liveness: unless forced open, the machine admits a call again within a few
	// timeout periods, whatever happened before.
	if m.Mode() == circuit.ModeForcedOpen {
		adm, _ := m.Admit(now.Add(100 * openTimeout))
		if adm.Reject != circuit.RejectedOpen {
			t.Fatalf("forced-open machine admitted a call: %+v", adm)
		}
		return
	}
	admitted := false
	for range 3 {
		now = now.Add(openTimeout + probeTimeout)
		if adm, _ := m.Admit(now); adm.Reject == circuit.Admitted {
			admitted = true
			break
		}
	}
	if !admitted {
		t.Fatalf("machine stuck: no call admitted after 3 timeout periods (ops %v)", ops)
	}
}
```

```go
// Command gate runs the GoSaf vs gobreaker benchmarks and fails if GoSaf is
// slower or allocates more on the hot paths. Run it before every release:
//
//	cd bench && go run ./gate
package main

import (
	"bufio"
	"fmt"
	"os"
	"os/exec"
	"slices"
	"strconv"
	"strings"
)

// tolerance is how much slower (as a fraction) GoSaf may be before the gate fails.
const tolerance = 0.02

type result struct {
	nsOp     float64
	allocsOp float64
}

// pair names the GoSaf and gobreaker benchmarks that must be compared.
type pair struct{ label, gosaf, gobreaker string }

var pairs = []pair{
	{"Closed, success", "BenchmarkGoSafClosedSuccess", "BenchmarkGobreakerClosedSuccess"},
	{"Open, reject", "BenchmarkGoSafOpenReject", "BenchmarkGobreakerOpenReject"},
}

// parse reads `go test -bench -benchmem` output and returns the median ns/op
// and allocs/op per benchmark name (the -N CPU suffix is removed).
func parse(output string) map[string]result {
	ns := map[string][]float64{}
	allocs := map[string][]float64{}
	sc := bufio.NewScanner(strings.NewReader(output))
	for sc.Scan() {
		f := strings.Fields(sc.Text())
		if len(f) < 4 || !strings.HasPrefix(f[0], "Benchmark") {
			continue
		}
		name := f[0]
		if i := strings.LastIndex(name, "-"); i > 0 {
			name = name[:i]
		}
		for i := 2; i+1 < len(f); i++ {
			v, err := strconv.ParseFloat(f[i], 64)
			if err != nil {
				continue
			}
			switch f[i+1] {
			case "ns/op":
				ns[name] = append(ns[name], v)
			case "allocs/op":
				allocs[name] = append(allocs[name], v)
			}
		}
	}
	out := map[string]result{}
	for name, v := range ns {
		out[name] = result{nsOp: median(v), allocsOp: median(allocs[name])}
	}
	return out
}

func median(v []float64) float64 {
	if len(v) == 0 {
		return 0
	}
	s := slices.Clone(v)
	slices.Sort(s)
	if len(s)%2 == 1 {
		return s[len(s)/2]
	}
	return (s[len(s)/2-1] + s[len(s)/2]) / 2
}

// verdict reports whether GoSaf passes against gobreaker and why not.
func verdict(gs, gb result) (bool, string) {
	var why []string
	if gs.nsOp > gb.nsOp*(1+tolerance) {
		why = append(why, fmt.Sprintf("slower by %.1f%% (limit %.0f%%)", (gs.nsOp/gb.nsOp-1)*100, tolerance*100))
	}
	if gs.allocsOp > gb.allocsOp {
		why = append(why, fmt.Sprintf("%.0f allocs/op vs %.0f", gs.allocsOp, gb.allocsOp))
	}
	return len(why) == 0, strings.Join(why, "; ")
}

func main() {
	cmd := exec.Command("go", "test", "-run=^$", "-bench=ClosedSuccess$|OpenReject$",
		"-benchmem", "-count=10", "-benchtime=300ms", ".")
	cmd.Stderr = os.Stderr
	out, err := cmd.Output()
	if err != nil {
		fmt.Fprintln(os.Stderr, "benchmarks failed:", err)
		os.Exit(2)
	}

	res := parse(string(out))
	failed := false
	fmt.Printf("%-18s %12s %12s %8s   %s\n", "path", "GoSaf ns/op", "gobreaker", "allocs", "result")
	for _, p := range pairs {
		gs, okA := res[p.gosaf]
		gb, okB := res[p.gobreaker]
		if !okA || !okB {
			fmt.Fprintf(os.Stderr, "missing benchmark results for %s\n", p.label)
			os.Exit(2)
		}
		ok, why := verdict(gs, gb)
		status := "PASS"
		if !ok {
			status, failed = "FAIL: "+why, true
		}
		fmt.Printf("%-18s %12.1f %12.1f %3.0f/%-3.0f   %s\n", p.label, gs.nsOp, gb.nsOp, gs.allocsOp, gb.allocsOp, status)
	}
	if failed {
		os.Exit(1)
	}
}
```

````markdown
Every release follows this checklist, in order. Do not tag until every box is ticked.
````

````markdown
### Operating the breaker
````
